### Question 26 of 248

You are attempting to install the Falcon sensor on a host with a slow Internet connection and the installation fails after 20 minutes. Which of the following parameters can be used to override the 20 minute default provisioning window?

- ProvNoWait=1✅

### Answer

- **ProvNoWait=1** skips the wait entirely. The install completes even if the sensor can't reach the cloud yet, and it finishes provisioning later when it connects. This is common for golden images or hosts that are temporarily offline.
- **ProvWaitTime**=<milliseconds> extends the provisioning window. The default is 1200000 (20 minutes); for example, ProvWaitTime=3600000 gives it an hour to reach the cloud.

```
WindowsSensor.exe /install /quiet /norestart CID=<CID> ProvNoWait=1
WindowsSensor.exe /install /quiet /norestart CID=<CID> ProvWaitTime=3600000
```
